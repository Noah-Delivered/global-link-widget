# 글로벌링크 위젯형 · 체험 사이트

버전 0.16.1 · 강조 색 변경 시 호버·연한 배경·강조 글자색 파생 적용, GitHub Pages 배포

배포 주소: https://noah-delivered.github.io/global-link-widget/ (저장소 Noah-Delivered/global-link-widget, public)

## 대상과 목적

주요 사용자는 글로벌링크 위젯형 도입을 검토하는 가맹점 직원입니다. 개발 지식 없이도 다음을 이해하도록 구성했습니다.

- 위젯이 쇼핑몰에서 하는 역할
- 실제 쇼핑몰에 설치되는 방식
- 운영·유지보수에 필요한 작업 범위
- 언어·국가·디자인 설정 방법

## 실행

이 폴더를 HTTP 서버 루트로 제공하고 index.html을 엽니다.

    python3 -m http.server 8777
    http://localhost:8777/index.html

- index.html: 체험 사이트(좌측 단계 안내 + 중앙 미리보기)
- demo-mall/index.html: 가상 쇼핑몰 뷰티라운지. 상점명·색상을 파라미터로 바꿀 수 있음. 상품 8종은 컬리 뷰티(kurly.com/main/beauty)에서 2026-09-10 수집한 실제 상품(설화수·세타필·메이크업포에버 4종·크리니크·스킨수티컬즈)이며 가격·옵션·품절(립밤 600 애니웨어 카페인, 컬러 펜슬 03 쿨 에보니)은 수집 시점 값. 이미지는 컬리 CDN 주소를 직접 참조하고, 단건 구매의 원본 URL은 kurly.com/goods/{id}
- widget/gl-widget.js: 위젯 본체

## 화면 구성

좌측은 5단계 안내, 중앙은 고정된 미리보기입니다. 좌측만 스크롤되고 페이지 전체는 스크롤하지 않습니다.

| 단계 | 내용 | 직접 해보기 |
|---|---|---|
| 1 무엇을 하나요 | 문제와 해결, 주문 흐름 3단계, 기존 쇼핑몰 무변경 표 | 접속 국가 전환(미국·일본·한국) |
| 2 설치 | 설치 코드 한 줄, 붙이는 위치 예시 소스, 설치 후 확인 3가지 | 한 줄 붙이기 · 설치 전으로 되돌리기(미리보기 실제 전환) |
| 3 설정 | 우리 쇼핑몰처럼 보기, 표시 대상·국가·제외 국가, 언어·통화, 모양·강조 색 | 모든 항목 즉시 미리보기 반영 |
| 4 운영 | 위젯이 읽은 것(상품·브랜드·옵션·품절·주문 상한), 잘못 인식된 정보 수정 방법, 주문 흐름 | 화면에서 요소를 클릭해 인식 위치 지정(상품명·브랜드·이미지·옵션), 설치 코드 자동 갱신, 자동 번역 켜기·끄기와 결과 확인 |
| 5 유지보수 | 현재 상태, 역할 분담표, FAQ, 체험 범위 안내, 요약 복사 | 상태 값 실시간 갱신 |

미리보기 상단: 메인·상품 상세 이동, PC·모바일 전환, 접속 국가 칩(클릭 시 미국→일본→한국 순환), 전체 화면(Esc 종료).
미리보기 하단 안내: 설치 전·한국 접속·판매 제외 국가일 때 위젯이 없는 이유를 표시.

## 설치 전·후 비교 구현

위젯에 `data-gl-enabled`(설정 override `enabled`) 플래그를 추가했습니다. false면 위젯이 그려지지 않고 상태 `reason: not-installed`만 보냅니다. 체험 사이트의 한 줄 붙이기·되돌리기가 이 값을 전환합니다.

## 우리 쇼핑몰처럼 보기 구현

데모몰이 `mall` 파라미터(JSON: name, en, color)를 읽어 로고·문서 제목·푸터 회사명·대표 색을 바꿉니다. 실제 쇼핑몰과는 무관한 미리보기용 기능입니다.

## 잘못 인식된 정보 수정 방법

수동 입력은 없습니다. 브라우저 개발자도구의 요소 선택기처럼 동작합니다.

1. 항목(상품명·브랜드명·대표 이미지·옵션)의 `화면에서 선택`을 누름
2. 미리보기 위에 마우스를 올리면 선택될 영역이 강조되고, 클릭하면 그 요소를 가리키는 CSS 선택자를 자동 생성
   - id 우선, 없으면 class(상태성 class 제외) 최대 2개, 없으면 순서(nth-of-type). 유일해질 때까지 부모를 붙이며 class나 id가 최소 하나 포함되도록 함
   - 이미지는 img 요소만, 옵션은 select 요소만 허용
   - 옵션은 복수 지정: 선택 모드가 유지되어 드롭다운을 차례로 클릭하면 선택자가 쉼표로 누적되고(이미 잡히는 드롭다운은 건너뜀), 완료 버튼 또는 Esc로 마침. 구조가 같은 드롭다운은 한 번 클릭으로 함께 잡힘
3. 선택자는 설정에 저장되고 설치 코드에 자동 추가됨. 설치 코드는 좌측 상단 고정 바에 단계와 무관하게 항상 표시되며, 변경 시 바가 잠시 강조되고 "설정 N개 반영" 배지가 붙음. 3단계 설정(표시 대상·판매 제외 국가·언어·통화·모양·강조 색)도 기본값과 다를 때 data-gl-overseas-only, data-gl-exclude-countries, data-gl-lang, data-gl-currency, data-gl-launcher, data-gl-theme 속성으로 함께 반영됨. 미리보기 접속 국가와 쇼핑몰 이름·색은 체험용이라 코드에 들어가지 않음. 설치 코드에 `data-gl-sel-name` `data-gl-sel-brand` `data-gl-sel-image` `data-gl-sel-options` 속성으로 자동 추가됨. 2단계 설치 코드와 4단계의 코드가 같은 값을 보여 주며, 추가된 속성은 강조 표시
4. 위젯은 지정 선택자를 자동 인식(JSON-LD·OpenGraph·화면)보다 우선 적용. 같은 쇼핑몰의 다른 상품 페이지에도 동일 적용
5. 해제 버튼 또는 지정 모두 해제로 자동 인식으로 복귀

번역은 자동입니다. `data-gl-translate`가 auto(기본)이고 접속 언어가 한국어가 아니면 위젯이 상품명·브랜드명·옵션 이름·옵션 값을 번역해 표시합니다. 숫자·가격은 번역하지 않습니다. 사용 안 함으로 끄면 설치 코드에 `data-gl-translate="off"`가 붙습니다. 콘솔의 자동 번역 탭은 켜기·끄기와 결과 확인만 제공하며 직접 고치는 칸은 없습니다.

프로토타입은 공개 번역 API(MyMemory)를 브라우저에서 호출하고 결과를 브라우저에 저장합니다(익명 일일 한도 있음). 번역 품질은 고르지 않으며(예: "1개"가 "Showing the single result"로 번역되는 사례 확인), 운영에서는 딜리버드코리아 서버가 번역·검수·캐시를 담당하는 구조를 전제로 합니다. 이전 버전의 상품별 수동 수정과 번역 입력 칸은 제거했습니다.

## 위젯 PC 패널 2단 그리드

PC에서 상품 패널과 장바구니는 폭 780px, 2단 구성입니다. 모바일 바텀시트와 빈 장바구니는 1단을 유지합니다.

- 왼쪽 300px: 대표 이미지(3:2), 브랜드, 상품명, 가격(USD·KRW), 진행 3단계, 슬로건·안내
- 오른쪽: 옵션·수량 선택, Add to Bag·Buy Now(하단 고정), 결제 수단, 장바구니 미리보기
- 두 열은 각각 스크롤하며, 행동 버튼은 오른쪽 열 하단에 고정되어 장바구니 미리보기가 길어져도 항상 보임
- 장바구니: 왼쪽 담은 상품 목록(수량 조절·삭제·개별 구매), 오른쪽 300px 요약 카드(수량·소계 USD·KRW·Checkout·안내), 결제 수단, 진행 3단계. 패널 높이는 내용에 맞춰 줄어듦
- 구현: buildProductUI(p, 'wide')가 상품 정보 블록과 옵션 블록을 분리 생성. 같은 DOM 노드를 두 곳에 넣을 수 없어 레이아웃별로 필요한 트리만 만듦

## 정확성에 관한 원칙

- 인식 결과 카드는 위젯이 실제 읽은 근거(JSON-LD 경로, meta 태그, HTML 요소)를 그대로 보여 줍니다. 근거는 접힌 상태로 두어 비개발자에게 부담을 주지 않습니다.
- 상품 페이지가 아닐 때는 '상품 페이지가 아닙니다', 표시가 있어도 정보가 부족하면 '상품 정보가 부족한 페이지'로 구분합니다.
- 주문 상한과 실제 재고는 다르다고 명시합니다.
- 체험 범위(결제 미연동, 설정은 브라우저에만 저장, 단건 구매는 실제 DK 상품 조회 페이지 연결)를 5단계에 표시합니다.
- 운영 서비스(파트너 콘솔 저장·배포, 서버 IP 국가 판별, widget.delivered.co.kr 배포)는 설명상의 운영 모델이며 이 프로토타입에 구현된 것이 아닙니다.

## 이번 검증

- 브라우저 1700·1440·1180·1024·900·820·390·360px: 페이지 전체 스크롤 없음, 좌측 안내만 스크롤, 미리보기 고정, 가로 넘침 없음
- 접속 국가 전환: 한국 접속 시 위젯 미표시와 안내 오버레이
- 설치 전·후 전환: 위젯 DOM 부재/존재, 상태 reason not-installed, 체크리스트 자동 체크
- 우리 쇼핑몰처럼 보기: 상점명·영문·색상이 로고·제목·푸터·주소 표시에 반영
- 강조 색·원형 버튼·일본어 자동 전환 반영
- 인식 결과 카드: 립밤(옵션 1종 9개 값, 품절 1개, 상한 5개), 컬러 펜슬 품절 1개, 자음 2종 세트 옵션 없음
- 요소 선택: 브랜드(div.pd-brand), 옵션(div.selw > select), 이미지(div.gal.product-detail__gallery > img) 지정 → 설치 코드 속성 추가, 다른 상품 페이지(P2)에서도 지정 위치로 인식
- 자동 번역: English·日本語 접속에서 번역 중 → 번역 완료, 위젯 주문 화면과 콘솔 번역 결과 표에 반영. 사용 안 함 시 원문 표시와 data-gl-translate="off" 추가
- 모바일 미리보기 영역 내 배치, 전체 화면 진입·Esc 종료
- 데모몰의 위젯 로드에 버전 파라미터(?v=0.12.0)를 붙여 브라우저 캐시로 인한 구버전 로드를 방지
