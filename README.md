# 글로벌링크 위젯형 프로토타입

딜리버드코리아 글로벌링크 위젯형의 방향성을 확인하기 위한 프로토타입입니다.

- 체험 주소: https://noah-delivered.github.io/global-link-widget/
- 구성: `index.html` 단일 파일
- 용도: 개발 참고용 기준 구현. 영업 시연 자료로 사용하지 않음

## 단일 파일 구성

`index.html` 하나에 다음 셋이 모두 들어 있습니다.

| 구성 | 역할 |
|---|---|
| 체험 화면 | 좌측 단계 안내와 중앙 미리보기로 도입 과정을 따라가는 화면 |
| 데모 쇼핑몰 | 가맹점 쇼핑몰 역할의 가상 사이트(뷰티라운지) |
| 위젯 본체 | 글로벌링크 위젯형. 실제 서비스에서는 별도 파일로 배포 |

데모 쇼핑몰과 위젯은 base64로 담아 두고, 실행 시 미리보기 영역에 문서를 만들어 넣습니다. HTML 파서가 문서 안의 태그를 잘못 끊는 것을 막기 위한 방식입니다.

## 실행

웹 서버로 열어야 모든 기능이 동작합니다.

```
python3 -m http.server 8777
http://localhost:8777/index.html
```

파일을 직접 열면 브라우저 보안 정책에 따라 화면에서 선택과 설정 저장이 제한될 수 있습니다.

## 체험 순서

| 단계 | 내용 |
|---|---|
| 1 무엇을 하나요 | 문제와 해결, 주문 흐름, 접속 국가 전환 |
| 2 설치 | 설치 코드 한 줄, 붙이는 위치, 설치 전후 전환 |
| 3 설정 | 쇼핑몰 이름·색상, 노출 조건, 언어·통화, 모양 |
| 4 운영 | 인식 결과 확인, 인식 위치 지정, 자동 번역 |
| 5 유지보수 | 현재 상태, 역할 분담, 자주 묻는 질문 |

설치 코드는 화면 왼쪽 위에 항상 표시되며, 설정을 바꾸면 즉시 반영됩니다.

## 데모 상품

컬리 뷰티에서 2026년 9월 수집한 실제 판매 상품 8종입니다. 가격·옵션·품절 상태는 수집 시점 값이며, 이미지는 컬리 CDN 주소를 참조합니다.

## 프로토타입에 없는 것

설정·번역·수집·모니터링 서버, 결제 연동, 실제 가맹점 검증, 성능 최적화는 포함되어 있지 않습니다. 상세한 범위와 개발 시 권장 방안은 제품 요구사항 정의서를 참고해 주세요.
